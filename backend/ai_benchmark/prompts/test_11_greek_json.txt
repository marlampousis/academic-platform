Σου παρέχονται δομημένες πληροφορίες σχετικά με έναν ακαδημαϊκό υποψήφιο.

Εξήγαγε τις βασικές ακαδημαϊκές πληροφορίες του υποψηφίου χρησιμοποιώντας αποκλειστικά το παρεχόμενο προφίλ.

Επέστρεψε ΜΟΝΟ έγκυρο JSON. Μην χρησιμοποιήσεις Markdown, σχόλια, επεξηγήσεις ή οποιοδήποτε κείμενο εκτός του JSON object.

Χρησιμοποίησε ακριβώς την ακόλουθη δομή:

{
  "ονοματεπώνυμο": "",
  "ειδίκευση": "",
  "ερευνητικοί_τομείς": [],
  "ανώτατος_τίτλος_σπουδών": {
    "τύπος": "",
    "τίτλος": "",
    "γνωστικό_αντικείμενο": "",
    "ίδρυμα": "",
    "χώρα": "",
    "έτος_ολοκλήρωσης": null
  },
  "δημοσιεύσεις": [
    {
      "τίτλος": "",
      "έτος": 0
    }
  ],
  "ερευνητικά_έργα": [
    {
      "τίτλος": "",
      "ακρωνύμιο": "",
      "ρόλος": ""
    }
  ],
  "διδακτική_εμπειρία": [
    {
      "μάθημα": "",
      "ακαδημαϊκό_έτος": "",
      "επίπεδο": "",
      "ρόλος": ""
    }
  ]
}

Κανόνες:
1. Χρησιμοποίησε μόνο πληροφορίες που αναφέρονται ρητά στο παρεχόμενο προφίλ.
2. Μην συμπεραίνεις, υποθέτεις ή επινοείς πληροφορίες.
3. Οι τιμές του JSON πρέπει να είναι στα ελληνικά όταν η αντίστοιχη πληροφορία παρέχεται στα ελληνικά.
4. Διατήρησε τις επίσημες ονομασίες ιδρυμάτων και οργανισμών όπως εμφανίζονται στο παρεχόμενο προφίλ.
5. Για το πεδίο "ανώτατος_τίτλος_σπουδών", επίλεξε αποκλειστικά τον ανώτερο ακαδημαϊκό τίτλο που αναφέρεται στο προφίλ.
6. Συμπερίλαβε όλες τις δημοσιεύσεις που αναφέρονται στο προφίλ και μην προσθέσεις άλλες.
7. Συμπερίλαβε όλα τα ερευνητικά έργα που αναφέρονται στο προφίλ και μην προσθέσεις άλλα.
8. Συμπερίλαβε όλη τη διδακτική εμπειρία που αναφέρεται στο προφίλ και μην προσθέσεις άλλα μαθήματα.
9. Αν μία ζητούμενη scalar πληροφορία δεν είναι διαθέσιμη, χρησιμοποίησε null.
10. Αν δεν υπάρχουν διαθέσιμα στοιχεία για μία ζητούμενη λίστα, χρησιμοποίησε κενό array [].
11. Μην προσθέσεις πεδία που δεν υπάρχουν στην απαιτούμενη δομή.
12. Μην συμπεριλάβεις h-index, citation metrics, τίτλο διδακτορικής διατριβής, βραβεία ή άλλες μη ζητούμενες πληροφορίες.
13. Μην αξιολογήσεις, κατατάξεις ή συγκρίνεις τον υποψήφιο.
14. Μην κάνεις σύσταση ή απόφαση σχετικά με πρόσληψη, επιλογή ή επιλεξιμότητα.
15. Το τελικό αποτέλεσμα πρέπει να είναι συντακτικά έγκυρο JSON.
